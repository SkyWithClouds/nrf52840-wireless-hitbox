# 单板无线 Hitbox

18 个常开按键、一块 NOLOGO ProMicro nRF52840。插数据线可在 Windows 用 XInput 玩游戏，同时在浏览器改键；拔线后，同一套 SOCD、方向设置和映射通过 2.4 GHz ESB 发给现有 v1.0 接收器。固件采用 MIT 许可证。

[打开 WebHID 配置台](https://skywithclouds.github.io/nrf52840-wireless-hitbox/) · [固件构建与下载](https://github.com/SkyWithClouds/nrf52840-wireless-hitbox/actions/workflows/build.yml) · [Pages 部署记录](https://github.com/SkyWithClouds/nrf52840-wireless-hitbox/actions/workflows/pages.yml)

## 三个仓库，四种组合

| 发射端 ↓ / 接收端 → | A · Windows PC 迷你接收器 | B · GP2040-CE 主机接收盒 |
|---|---|---|
| A · 成品 GP2040-CE Hitbox 外挂 | ① Pico Host + ② radio-tx → ④ usb-rx | ① Pico Host + ② radio-tx → rx-bridge + ⑤ gp2040-rx |
| B · 本仓库单板 18 键 | ③ hitbox-nrf52840 → ④ usb-rx | ③ hitbox-nrf52840 → rx-bridge + ⑤ gp2040-rx |

编号对应五份核心固件。接收端 B 的 NOLOGO #2 还需单独刷其配套的 **rx-bridge**。PS4/PS5 等主机模式与实体认证器由接收盒处理，PS5 游戏须支持相应街机摇杆模式。[外挂发射端和 PC 接收器](https://github.com/SkyWithClouds/gp2040-wireless) · [主机接收盒与认证器接线](https://github.com/SkyWithClouds/gp2040-wireless-console)


## 无线匹配与双打（v1.1 预览）

出厂网络 ID 为 `B74632DA`，信道 40，速率 2 Mbps。槽位 1 在本机使用 Pipe 1，其基础地址与前缀 C5 保留旧 Pipe 0 的空口地址，原版 v1.0 板可继续配合使用。Slot 2–4 需要升级对应发射板和 PC 接收器。玩家槽位决定无线输入路由到哪个 XInput 接口；Windows 和游戏自行分配控制器序号。

1. 在桌面 Chrome / Edge 用 USB 数据线连接要配置的无线板，打开[WebHID 配置台](https://skywithclouds.github.io/nrf52840-wireless-hitbox/)。修改外挂发射板或主机盒无线桥前，断开板间供电和信号线，单独给 NOLOGO 插 USB。
2. 在「无线匹配与接收器管理」生成一次网络 ID，给同一组设备填写相同的八位 ID 和信道。信道 2–80 对应 2402–2480 MHz。不同比赛台可分别选 ID；同频设备仍共享空口时间。
3. PC 接收器默认启用 2 个槽位，可设 1–4。两台发射端分别选 1、2。主机盒固定使用槽位 1，允许修改 ID、信道。每台保存后等待回读，再完全断电重启；单板 Hitbox 拔线进入无线即加载已保存的设置。
4. PC 接收器网页每约 150 ms 显示每槽状态、收到的有效帧、漏收心跳、重复输入和超时次数，计数从开机开始。漏收心跳按同一会话的心跳编号缺口累计，真实射频丢包率需借助空口测量。
5. 双打实测时让两人同时点按，按住 1P 后断开 1P 电源，检查 1P 释放、2P 仍可操作。交换角色重复，再测修改信道、恢复出厂参数和断电保存。USB 枚举、射频吞吐及实际输入延迟待实板验证。

## 接线与刷机

每个按键一端接表中 GPIO，另一端接 GND，按下为低电平。板上启用内部上拉。省略的排针包括连接地、电源或复位的脚，请按实板 Pin 1 标记数脚。

| 键 | NP1 排针 | GPIO | 出厂动作 | 键 | NP2 排针 | GPIO | 出厂动作 |
|---:|---:|---|---|---:|---:|---|---|
| 1 | 2 | P0.06 | 左 | 11 | 1 | P0.09 | RT |
| 2 | 3 | P0.08 | 下 | 12 | 2 | P0.10 | LT |
| 3 | 6 | P0.17 | 右 | 13 | 3 | P1.11 | Back |
| 4 | 7 | P0.20 | 上 | 14 | 4 | P1.13 | Start |
| 5 | 8 | P0.22 | X | 15 | 5 | P1.15 | LS 点击 |
| 6 | 9 | P0.24 | Y | 16 | 6 | P0.02 | RS 点击 |
| 7 | 10 | P1.00 | RB | 17 | 7 | P0.29 | Guide |
| 8 | 11 | P0.11 | LB | 18 | 8 | P0.31 | AUX |
| 9 | 12 | P1.04 | A | | | | |
| 10 | 13 | P1.06 | B | | | | |

AUX 对应生态按钮位 11，Windows 游戏对该保留位的支持各异；可在网页重新分配。NP3 外设出厂均关闭，接法见下表。电池使用板厂支持的单节 3.7 V 锂电池，正负极接 B+ / B−；充电由板载电路管理。**严禁把 USB 5 V 接 BAT 或 GPIO。** [板厂引脚与供电说明](https://www.nologo.tech/product/otherboard/NRF52840.html)

1. 在 **Actions → Hitbox CI** 打开同一提交的成功运行，下载并解压 Artifact。使用其中的 `hitbox-nrf52840-nologo-26000.uf2`。
2. 用 USB 数据线连接发射板，把 RST 与 GND 快速短接两次，进入 UF2 引导盘。核对 `INFO_UF2.TXT` 的 Bootloader 0.6.0、nice!nano、S140 6.1.1，拖入 UF2。启用 NFC 引脚作 GPIO 的首次启动可能自动复位一次。
3. Windows 打开 `joy.cpl` 测有线输入。保持 USB 连接，用桌面 Chrome 或 Edge 打开配置台，点击「连接设备」并选择发射板。网页连接的是 Interface 1，游戏使用 Interface 0。
4. 点击面板上的物理按键后选择动作；选项卡切换编辑对象，「启动配置档」决定保存后启用的配置。点击「保存到设备」，等写入和回读完成。JSON 导入后也需保存。映射为「下一配置」的实体键可临时循环切换，松开所有键后即可再次切换；下次开机使用保存的启动配置。
5. 装电池、拔掉 USB，给一台接收器通电。测试另一种组合时关闭上一台接收器。充电宝或纯充电线也会拉高 VBUS，此时板子进入有线模式。

四种 SOCD 为中立、上优先（左右仍中立）、后输入优先、先输入优先。同一消抖扫描内同时按下的相反方向没有先后，先/后优先模式输出中立。消抖为各键独立 1–10 ms，默认 2 ms。方向可输出 D-Pad、LS 或 RS。多个物理键可以映射到同一动作，四个配置档在一次 NVS 事务中保存。

## v1.2 连发、宏与外设

用 USB 连接后打开配置台。「保存到设备」一次写入四个映射档及共用的外设、连发和六组宏，并回读校验。升级会读取原 v1.0/v1.1 按键档和无线匹配参数。出厂关闭 RGB、玩家指示和连发，宏序列为空。旧版 JSON 可以导入，网页保留当前外设与宏设置。[WebHID 配置台](https://skywithclouds.github.io/nrf52840-wireless-hitbox/)

| NP3 / 电源 | 用途 | 接法 |
|---|---|---|
| P1.02、P1.07 | 128×64 单色 OLED | 分别接 SDA、SCL，模块 VCC 接 EXTVCC，GND 共地。两根线各用约 4.7 kΩ 上拉至 **EXTVCC**，检查模块是否已有上拉。页面选择 SSD1306 或 SH1106 及 7 位地址 0x3C / 0x3D。 |
| P1.02、P1.07 | 二进制 LED0、LED1 | 与 OLED 二选一。每路由 EXTVCC → 独立 1 kΩ 电阻 → LED 正极，LED 负极接对应 GPIO。GPIO 拉低点亮。 |
| P1.01 | WS2812B / SK6812 **RGB** 数据 | 接第一颗 DIN（建议串 220–330 Ω，DIN 到 GND 接 10 kΩ 下拉），顺序级联，灯带电源接 EXTVCC，GND 共地。按 24 位 GRB、800 kHz 输出。选数据手册明确支持实际 3.3 V 供电的型号。RGBW 四通道和要求 5 V 的灯带需不同驱动或供电设计。 |
| P0.13 | 板内开关 | NPU1（ME6217）脚 3 EN 接 POWER_PIN，脚 5 输出 EXTVCC。应用拉高开启、拉低关闭。换批次先空载量 VCC 对 GND，在网页切换关闭 / 静态有光验证极性。引导程序期间 EN 受板上上拉影响。 |

**供电与亮度。** RGB、OLED 及双 LED 共用受控 3.3 V。高阻态和外部上拉均须随此电源域断电。固件先使能、等待电源稳定，再启用通信。最后一个亮灯请求结束时释放三根信号线、拉低 EN。OLED 单独息屏时若 RGB 仍亮，则发送显示关闭指令并释放 I²C。不要把灯带的外部电源并入板载 EXTVCC。ME6217 约 300 mA 的标称能力受电池电压、压差和散热限制。网页和固件将亮度限制在 0–64/255（默认 16），固件还逐帧按每颗静态 1 mA、满量程每色 20 mA 的模型，将 RGB 预算限制为 100 mA，给 OLED 和板载负载留余量。实际电流取决于灯珠批次，首次接入先用一颗低亮度测量。[板厂供电说明](https://www.nologo.tech/product/otherboard/NRF52840.html) · [NOLOGO 电路图](https://github.com/sasodoma/nrf52840-promicro/blob/main/schematic.png)

- **OLED 和玩家灯**。图上实心按键对应物理按下。底栏显示 SOCD、D-Pad / LS / RS、玩家编号、USB / RF、估算电量、Turbo 脉冲和运行中的宏编号。30 或 60 秒无按键后息屏，按键唤醒。双 LED 的五行分别保存离线或灭灯、1P、2P、3P、4P 的亮灭组合，高位为 LED1。主机编号命令优先，未收到编号时使用已连接设备的槽位；显式灭灯和未连接都使用第 0 行。两灯共四种图案，五行可以复用图案。
- **Turbo**。选择 5–30 Hz，勾选允许的逻辑动作。勾选项默认以约 50% 占空比连发。把某一实体键映射为 Turbo，和目标键一起按即可切换该动作；松开目标键后再按生效。临时开关在换档、传输模式切换、写入设置或重启后恢复为勾选状态。
- **宏**。六组共用序列，每组最多七步。每步可同时选择方向、按键和扳机，持续 1–65535 ms，随后间隔 0–65535 ms。选择单次播放、按住循环（松开即停）或再按打断，再把所需档位中的任意实体键映射到宏 1–6。物理输入与宏步骤先合并，再按当前档执行 SOCD 和方向输出。多个宏可同时播放。游戏输入每毫秒最多生成一个快照。
- **RGB**。选择 1–18 颗并填写实际数量。按键灯按接线表物理键 1–18 对应灯珠 1–18。静态、按键和呼吸使用所选颜色，彩虹自动换色。PWM0 EasyDMA 输出灯带数据；低优先级外设线程刷新屏幕，输入扫描和无线窗口独立运行。

## 电池与休眠

内部 SAADC 采 P0.04/AIN2。不同批次可能未装该采样支路；确认本板分压比后，可在网页设置电压倍率（电池电压除以 ADC 引脚电压）。默认未校准时，只在电池供电期间从 VDDH/5 估算。插 USB 后展示最近一次拔线读数；USB 冷启动无历史值时显示「待测」。百分比按单节锂电电压估算，充电或负载会影响读数。[板级差异与原理图](https://github.com/sasodoma/nrf52840-promicro)

无线连续 5 分钟没有物理按键活动且宏已结束时，固件停止 ESB、释放高频晶振并进入 **System ON 无滴答低功耗休眠**，CPU 阻塞等待 GPIO PORT/SENSE 或 USB 电源中断，保留 RAM。按住任一键继续游戏时保持唤醒。此选择可避免唤醒后重跑 UF2 引导程序。GPIO 唤醒、重新建立无线会话和主机收到首份报告各有独立耗时，实测时请分别记录。

## 协议、存储与构建

无线基线为原仓库的提交 `1967a24c27c0dbc7fd60f2adc065cb4a09c3a980`。协议编解码、Pico 源状态机和 PTX 滑动窗口直接复用。在同一 MCU 上把本地快照送入两段状态机，RF 数据保持 24 字节、64 位 session_id、CRC-8/SMBUS、出厂地址和默认 RF_CH 40、2 Mbps。保留原八类消息、32 帧源队列、8 帧窗口、usb_done 累计确认、1–2 ms 主动轮询、10 ms 心跳和 50 ms 看门狗。无线 STATUS 中的玩家灯在本机转换为玩家编号。双 LED 已应用映射或 OLED 成功写屏后，心跳可确认同一会话的 `led_gen`。关闭玩家指示、OLED 息屏或 I²C 写失败时保留待处理代数。[v1.0 规范](https://github.com/SkyWithClouds/gp2040-wireless/blob/1967a24c27c0dbc7fd60f2adc065cb4a09c3a980/docs/PROTOCOL_SPEC.md)

有线复合设备使用样机 VID/PID `1209:0003`。Interface 0 为 `XUSB10`，IN `0x81`（1 ms）、OUT `0x02`；Interface 1 为 HID Usage Page `0xFF60`，64 字节 Feature 报告双向配置，64 字节 Input 报告提供实时按键和电池遥测。出货前需使用产品自己的 USB 标识并同步修改网页过滤条件。

应用范围 `[0x26000,0xE8000)`，自建 NVS 占 `[0xE8000,0xEC000)`，引导程序原有的保留区从 `0xEC000` 开始。反复刷本固件会保留 NVS。UF2 使用 Family ID `0xADA52840`。SDK 依赖由 west 清单固定为 nRF Connect SDK v2.9.2。

- `scripts/test.sh` 还覆盖 5–30 Hz 连发、宏三种播放模式及毫秒计数回卷、自定义 LED 映射、OLED 帧缓冲、RGB 限流和电源门控。
- `scripts/test.sh` 使用 C 编译器和 Node.js 22 运行线格式、消抖、SOCD、配置事务，以及与两个现有接收器的互通测试。模拟链路包含丢包、ACK 丢失、停滞和重连。接收盒基线为 `9857d79a9078d2160d0cb4344fb29a4af9d2392e`。
- `.github/workflows/build.yml` 在 Nordic 工具链容器中运行 west，逐块比对 UF2 和链接后的二进制，检查目标地址、家族和复位向量。
- `.github/workflows/pages.yml` 部署 `web-configurator/`。本地预览可运行 `python3 -m http.server 8000 --directory web-configurator`，在浏览器打开 `http://localhost:8000`。

## 实板验收

- [ ] 先用 USB 同时打开 joy.cpl 和配置台，逐一按 18 键，核对引脚与网页高亮，再测快速点按、A+B 同按和长按。特别核对已释放 NFC 功能的 P0.09/P0.10。
- [ ] 分别测左→右、右→左、上下同按和松开一侧，核对四种 SOCD；将方向分别切到 LS、RS，核对轴和符号。
- [ ] 保存四个不同配置，完全断电再上电，核对启动档、映射、消抖、JSON 往返。网页应在有线游戏中持续显示按键。
- [ ] 分两次接 PC 迷你接收器和主机接收盒。每次测试快速点按、同时按、蓄力并在长按时断开发射板电源。重连只同步当前状态。主机盒先在 PC XInput 测，再按其说明接实体认证器与目标游戏。
- [ ] 用电池测试有线/无线来回切换；无线空闲超过 5 分钟后分别用各键、再用插 USB 唤醒。用同一时基记录 GPIO、首个有效无线包与主机输入，测待机电流。核对网页电压来源并与电池实测值比较。

- [ ] 刷机前导出旧 JSON。升级后先读回旧档，再把双 LED 的五种状态逐一改写。测试主机指派玩家、拔接收器、改槽位以及彻底断电后的读回。
- [ ] 选择对应 OLED 型号和地址，按 18 键观察图形，切换方向、SOCD、USB / RF 和宏标记。分别测 30 / 60 秒息屏及按键唤醒。
- [ ] 在 joy.cpl 录下 5 Hz 与 30 Hz 连发、Turbo 和 A 的组合切换，再试三种宏模式。分别换 PC 接收器与主机盒，在长宏期间拔下接收器检查清零与重连。
- [ ] 先单颗再接整串，逐项测静态、按键、呼吸、彩虹。分别让 OLED 或 RGB 单独熄灭，再全部关闭；量 EXTVCC、三根信号脚和全白电流，检查有线游戏输入在刷新屏幕时的时序。

自动化测试和云端构建覆盖软件路径。此款复合 USB 在 Windows 的实际驱动绑定、两种组合的真实射频表现、睡眠电流及首键延迟待实板验收。

## v1.3 现场调试

三仓继续使用 24 字节游戏帧与原有 50 ms 看门狗。以下管理功能需要对应 nRF 板的 v1.3 固件。用数据线连接该板，打开 [WebHID 配置台](https://skywithclouds.github.io/nrf52840-wireless-hitbox/)。

- **扫描**。固件分时测量 2402–2480 MHz 各频点，每点采四次 RSSI 并取峰值，推荐分数同时考虑本频点和左右 10 MHz。页面展示 dBm，越接近零表示干扰越强。点击采用后给同组其他板设置相同信道。单次快照可能错过突发干扰，约 200 ms 的扫描目标和掉帧情况待上板计时。
- **近场配对**。两板贴近，分别开启 15 秒配对窗口。单板 Hitbox 按住 AUX（Fn）+ LS 点击 + RS 点击两秒后全部松开；其余三款 nRF 管理固件支持在空闲 P1.07 与 GND 之间加装常开按钮，按两秒开窗。也可通过各板的 WebHID 按钮启动。接收器生成新网络 ID 并选频，发射端加入槽位 1。接收器的整组网络 ID 会变化，双打的其他板需要同步更新。配对期间游戏会话可自然超时并清零。
- **距离与掉电**。双方使用公共信道 76、−20 dBm、双随机数，逐包要求信号强于 −55 dBm。距离随天线、遮挡和反射变化；一次只给目标两板开窗。提交前的临时网络写入有回退记录，超时及中途重启恢复旧配置。若在一方完成最终提交之后切断另一方电源，两块独立 Flash 仍可能不同，可重新开窗配对。
- **免拆刷机**。网页点击「重启到 UF2 盘」，保持 USB 数据线连接，等磁盘出现再拖入对应固件。固件验证命令和魔数，主机读取应答后延迟复位。单板 Hitbox 也可在有线时按住 AUX + Back + Guide 五秒后松开。接收盒 Pico、发射端 Pico 以及独立的阶段 1 XInput 枚举测试镜像沿用原刷机流程。

**赛事设置**。选择「按下立即响应」后，按下会在首次检测到该输入的扫描中生效，释放须连续稳定满配置的消抖时间。关闭此选项恢复对称消抖。首次升级保留原档，新增选项默认关闭。将 AUX 当 Fn，先按 Fn 再按 Start + Back，三键连续保持两秒后全部松开，可切换并保存赛事锁。锁定时屏蔽 Start、Back、Guide，旁路连发、宏；勾选锁定时中立可覆盖档位 SOCD。网页实时状态及 OLED 显示 LOCK。启用 EXTVCC 后外设线程至少等待 12 ms 才驱动总线，断电前挂起 I²C、释放三根信号脚；I²C 外部上拉仍须接 EXTVCC。
